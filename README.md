## Описание проекта
Проект содержит реализацию двух заданий на Java 25 (LTS):
1. **Задание № 1 (`task1`):** Создание пользовательской аннотации `@Repeat`, анализ структуры класса `MyClass` через Reflection API и управляемый вызов защищённых (`protected`) и приватных (`private`) методов с аргументами.
2. **Задание № 2 (`task2`):** Управление структурой каталогов и файлов с использованием пакета `java.nio.file` (создание иерархий, копирование, маркированный рекурсивный обход `[D]`/`[F]` и каскадное удаление дерева каталогов).

---

## Сборка и запуск

### 1. Компиляция проекта
Из корневого каталога проекта выполните:
```bash
javac -d bin (Get-ChildItem -Recurse -Filter *.java).FullName
```
### 2. Запуск задания № 1 - Рефлексия и аннотации
```bash
java -cp out task1.Invoker
```
### 3. Запуск задания № 2 - Файловая система
```bash
java -cp out task2.FileSystemTask
```
